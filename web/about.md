# SkyRoads

SkyRoads was a MS-DOS video game created by Bluemoon Interactive that was released in 1993. I spent countless hours playing as a kid and still enjoy it, except Druidia Road 3 which can go straight to hell. I'm not convinced that it can be completed. I've seen people on Youtube do it but unless I see someone do it with my own eyes, I'm going to continue believing that it is impossible. Best of luck to you if you want to try.

I'm not going to claim to have "built" this, but I did spend a lot of time talking to Claude Opus 5.5 and when that refused to do what I asked it to ("Don't build a recreation of a specific existing game, even if it is renamed or called original."), Deepseek v4.1 Flash, which honestly was a little terrifying to watch as it spun itself in circles for over an hour but eventually barfed out a game that Opus happily continued building on.

Thanks for checking this out.
