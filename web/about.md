[SkyRoads](https://en.wikipedia.org/wiki/SkyRoads_(video_game)) was a MS-DOS video game created by [Bluemoon Interactive](http://www.bluemoon.ee/history/skyroads/index.html) that was released in 1993. I spent countless hours playing it as a kid and still enjoy it, except Druidia Road 3 which can go straight to hell. I'm not convinced that it can be completed. I've watched Youtube videos of it but unless I see someone finish it with my own eyes, I'm going to continue believing that it is impossible. Best of luck to you if you want to try.

If you've been hearing a lot about "low effort vibe-coded recomps", well, you're looking at one of them. I'm not going to claim to have "built" this, but I did spend a lot of time talking to Claude Code (Opus 5.5) and when that refused to do what I asked it to because of an internal prompt "Don't build a recreation of a specific existing game, even if it is renamed or called original.", Deepseek v4.1 Flash. It was a little terrifying to watch as Deepseek spun itself in circles for over an hour but it eventually barfed out a game that Claude happily continued building on, the end result of which is what you see here.
